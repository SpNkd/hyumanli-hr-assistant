# Demo guide

## Demo goal

Зритель должен понять: HR делает одно действие, а Humanly сам пишет уважительно, планирует вовремя, напоминает мягко и закрывает цикл после ответа.

## Scenario

1. **Overview.** Показать active requests, один `Ответ получен` и один `Нужен личный контакт`.
2. **Launch.** Нажать «Запустить коммуникацию», выбрать Дмитрия Ковалёва, eNPS, deadline +5 дней, поддерживающий тон.
3. **One click.** Запустить коммуникацию и показать два готовых письма, статус `Ждём ответ` и три события.
4. **Human tone.** Открыть письмо, показать короткий body, затем «5 вариантов тона».
5. **Explainability.** Открыть `Prompt preview`: контекст сотрудника, история, тон, ограничения и JSON output.
6. **Time safety.** Перейти в Timeline: follow-up изначально попадает на субботу, но сдвинут на понедельник в 10:00.
7. **No-response.** Нажать `+7д`: follow-up отправится, появится `Next check +2 рабочих дня`.
8. **Response cleanup.** Открыть активный запрос, нажать «Симулировать ответ», подтвердить. Follow-up и escalation станут архивными.
9. **Human escalation.** Открыть запрос Игоря: follow-up уже отправлен, escalation требует внимания, есть совет перейти к личному контакту.

## WOW moments

- **One-click launch:** одна кнопка создаёт request, два human-sounding draft и timeline.
- **Working-hours intelligence:** событие с выходного автоматически переносится на рабочий слот с объясняющим badge.
- **Zero-click cleanup:** ответ сотрудника сразу архивирует будущие напоминания.
- **Human escalation:** repeated non-response не превращается в бесконечный спам — HR получает рекомендацию для личного контакта.

## Fallback

- Если сеть недоступна, приложение продолжает работать: оно не зависит от внешних API.
- Если браузер блокирует localStorage, продукт всё равно работает до перезагрузки; можно нажать `Сбросить demo data`.
- Если нужно показать только главный эффект, откройте seed-запрос Игоря и затем Дмитрия; это покрывает no-response и human tone без ввода данных.
