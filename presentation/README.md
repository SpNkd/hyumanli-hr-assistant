## Как показывать

Оптимальный порядок — слайды 1–2, затем live demo в продукте, затем слайды 3–6. Общая защита с демонстрацией укладывается примерно в 4–5 минут: около 90 секунд на вводную часть, 2 минуты на demo-flow и около минуты на архитектуру и MVP-границы.

Слайды 2–3, 4 и 5 визуально поддерживают основной путь: Inbox → память Дмитрия → Decision/Guard → ответ и архивирование либо эскалация Игоря. На каждом слайде добавлены speaker notes с текстом выступления и переходом к следующей части.

## Запуск live demo

Из корня проекта:

```bash
node server.js
```

Открыть `http://localhost:4173` и пройти сценарий из [DEMO.md](../docs/DEMO.md). При отсутствии сети интерфейс остаётся доступным через локальный DemoProvider; для защиты не требуется ручное наполнение данных.
